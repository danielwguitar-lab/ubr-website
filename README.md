# UBR Website

> Unbreakable Through Resilience (UBR) — main website

## Overview

This repository contains the source code for the UBR main website. UBR is Daniel Walsh's personal development and publishing brand built on lived experience of ADHD, trauma, physical injury, and recovery.

## Tech Stack

- React + Vite + Tailwind CSS
- Deployed via Vercel (auto-deploy from main branch)
- GitHub: danielwguitar-lab/ubr-website

## Branching Strategy

- `main` — production (Vercel auto-deploys from here)
